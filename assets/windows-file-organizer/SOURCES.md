Os outros SVGs desta pasta foram desenhados para o CentralJogos. Os dois vídeos e pôsteres em `media/` são reproduzíveis executando:

```powershell
.\scripts\create-windows-file-organizer-media.ps1 -FfmpegPath C:\caminho\para\ffmpeg.exe
```

Os nomes e logotipos pertencem aos respectivos titulares e são usados apenas para identificação em uma atividade educacional independente.
